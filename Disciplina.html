Sobre o Curso de DS

Unidade: ETEC de Itanhaém
Período: Noturno

O que você aprende no curso?

O técnico em Desenvolvimento de Sistemas é capacitado para analisar, projetar, documentar, testar, implementar e manter sistemas de informação para plataformas web, desktop e dispositivos móveis.

  • Lógicas de Programação e Algoritmos
  • Desenvolvimento Web (HTML, CSS, JavaScript e PHP)
  • Banco de Dados e Modelagem de Dados
  • Desenvolvimento de Aplicativos Móveis
  • Engenharia de Software e Design de Interface (UI/UX)
